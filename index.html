Module implementation for ChromaDB vector indexing, TF-IDF cosine similarity retrieval, scheme eligibility filtering, and Streamlit UI.

1. Speech & Language Pipeline

Supports ml-IN (Malayalam) and en-IN (English) via Web Speech API and Python SpeechRecognition + gTTS.

2. Vector Store & RAG Engine

Indexes official KAU Package of Practices chunks in ChromaDB with TfidfVectorizer ngram (1,2) cosine similarity scoring.

3. Scheme Eligibility Engine

Evaluates farmer landholding (Ha), crop selection, and ownership status against 5 state and central agricultural schemes.
